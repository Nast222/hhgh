# 🎲 Random Task Generator — генератор случайных задач

## Автор: [Арина Г.]
## Описание

Простое GUI-приложение для генерации случайных задач из предопределённого списка. Позволяет выбрать задачу на день по категориям (учёба, спорт, работа), сохраняет историю сгенерированных задач в файл JSON и поддерживает фильтрацию по типу.

## 🛠️ Технологии

- Python 3.x.
- Tkinter (стандартная библиотека).
- random.
- JSON.
- Git.

## 📦 Требования

- Python 3.x.
- Библиотека tkinter (входит в стандартную поставку).

## 🚀 Запуск

1. Клонируйте репозиторий.
2. Перейдите в папку проекта.
3. Запустите: `python main.py`.

## ✨ Возможности

- Генерация случайной задачи одной кнопкой.
- Фильтрация задач по типу (учёба/спорт/работа).
- История выполненных/выданных задач.
- Сохранение состояния (истории) в `data/tasks.json`.
- Валидация данных при загрузке.
